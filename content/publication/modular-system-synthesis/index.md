This paper studies how to make program synthesis scale by exploiting modularity. Instead of synthesizing a large system in one monolithic search, the approach builds larger programs from smaller synthesized components.

The key idea is to structure the decomposition so that each subproblem remains similar in character to the original synthesis problem. This keeps the search spaces at different levels comparable and gives synthesis tools a path toward handling larger systems.

The work points toward synthesis workflows where modular system design is part of the synthesis process itself. It appeared at FMCAD 2023.
