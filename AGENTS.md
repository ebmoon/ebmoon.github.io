# Homepage

## Frontend design

For frontend design, redesign, critique, accessibility audits, responsive layout, or visual polish, read `skills/impeccable/SKILL.md` and follow the playbook for the requested work. For example, “Use Impeccable to audit the homepage” selects the `audit` playbook.

Use `skills/impeccable/` as the skill base directory. Resolve `.agents/skills/impeccable/` paths in the upstream instructions against this directory and run the launcher from the Homepage root. When the user requests live editing, set `IMPECCABLE_LIVE_COPY_AGENT=chat` when starting the server so copy edits go to the active conversation.

Impeccable 4.10.0 comes from [pbakaus/impeccable](https://github.com/pbakaus/impeccable/tree/b49177d32788f2dc585c42831d845dacf1ebed2c/.agents/skills/impeccable). The upstream license is in `skills/impeccable/LICENSE`.
